# Camera reference revision R1

[Download the complete CAD package](Camera_revision_R1.zip?raw=true) (approximately 4.4 MB).

The ZIP contains a colored STEP assembly for import into SOLIDWORKS, a FreeCAD document, before/after views, construction scripts, validation results, and comparison/import instructions.

This is an approximate reference-based revision, not an exact or manufacturing-approved replica. Native SOLIDWORKS feature history is not included. The exported STEP was reimported with OpenCascade: 33 valid solids with a 280 × 110 × 110 mm overall envelope. Mechanical fit and SOLIDWORKS import behavior have not been verified. See the comparison report inside the ZIP for remaining differences and estimated dimensions.
